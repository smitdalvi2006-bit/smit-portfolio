# Smit Dalvi — Personal Portfolio

A responsive single-page portfolio built with HTML, CSS, and vanilla JavaScript. The visual direction uses a midnight navy background, electric-blue/cyan accents, abstract motion, and a mix of technical and creative content.

## Sections
- Home / introduction
- About
- Selected work (portfolio site, AWS & Data Science learning, content & college communities)
- Skills and interests
- Contact placeholder links

## Run locally
Open `index.html` in a browser. No build tools are required.

## Publish with GitHub Pages
1. Create a **public** GitHub repository (for example `smit-portfolio`).
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/(root)`, then save.
4. Wait for deployment and open the URL GitHub displays.
5. Test the URL in a private/incognito window and on a phone.

## Personalize before submitting
- Add your own GitHub and LinkedIn URLs in the contact section when available.
- Add a public contact email if you want visitors to reach you directly. Do not publish a phone number or home address.
- Replace or expand project descriptions with accurate details and links to work you have actually completed.
- Add a profile photo only if you want one.
